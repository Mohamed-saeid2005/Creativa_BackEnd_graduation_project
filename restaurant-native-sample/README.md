# مشروع إدارة طلبات المطعم - Native PHP

## متطلبات التشغيل:
1. سيرفر محلي (XAMPP / WAMP / Laragon) أو PHP 8.x + MySQL.
2. استيراد ملف `database.sql` في خادم MySQL (اسم القاعدة: `restaurant_db`).
3. تعديل بيانات الاتصال في `config/db.php` إذا كانت لديك كلمة مرور لـ MySQL.

## بيانات تسجيل الدخول التجريبية:
- البريد: `admin@restaurant.com`
- كلمة المرور: `password
## التشغيل السريع:
من موجه الأوامر داخل هذا المجلد:
```bash
php -S localhost:8000
```
ثم افتح المتصفح على: `http://localhost:8000`
